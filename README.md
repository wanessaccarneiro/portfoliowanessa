# React portfolio for Wanessa Costa Carneiro — Psicóloga e Neuropsicóloga

Site built with React + Vite. Published via GitHub Pages.

## Dev

```bash
npm install
npm run dev
```

## Deploy

Configure o repositório no GitHub e rode:

```bash
npm run deploy
```

O site será publicado em `https://SEU-USUARIO.github.io/portfolio/`

## Estrutura

```
src/
├── components/
│   ├── Hero.jsx       — Seção de abertura
│   ├── About.jsx       — Sobre a profissional
│   ├── Specialties.jsx — Áreas de atuação
│   ├── Cognis.jsx      — Sobre a Cognis
│   ├── Contacts.jsx    — Contato + WhatsApp flutuante
│   └── Footer.jsx      — Rodapé
├── App.jsx
├── main.jsx
└── index.css
```
